Data Source: GEP (Overwolf) Spectra CV

To use Spectra CV Mode instead of GEP, you must configure your game correctly:

  • The game resolution must be set to exactly 1080p (1920x1080).
  • The game must be running in the foreground on your screen.
  • The Scoreboard must be open and visible.
  • The background behind the scoreboard must be black (AFK view).

Spectra CV will start analyzing the screen as soon as you confirm.
